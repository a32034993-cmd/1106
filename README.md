# Daylight 個人行程與任務管理系統

Daylight 是一個純前端互動原型，包含今日總覽、行事曆、任務、長期目標、提醒與共享空間示意。

## 預覽

開啟 `index.html` 即可在瀏覽器中查看。不需安裝套件或設定伺服器。

## 專案內容

- `index.html`：網站原型
- `build_prd.py`：產生產品需求文件的 Python 程式
- `PRD_Daylight_個人行程與任務管理系統.docx`：產品需求文件
- `prd_render/`：需求文件預覽頁面
- `assets/`：介面概念圖與預覽圖

> 這是示範原型。操作資料只存在目前頁面記憶體中，重新整理後會重設；登入、雲端同步和實際邀請功能尚未連接。
